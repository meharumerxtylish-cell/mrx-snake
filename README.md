# MR X Snake Pro 🐍

A polished Snake game in a **single HTML file** — no installs, no build step.

## Play
Just open `index.html` in any browser (phone or PC).

## Features
- Keyboard arrows + Space (start/pause)
- On-screen buttons and **swipe controls** for mobile
- Speed levels — the snake gets faster every 50 points
- Best score saved in the browser
- Gold & black MR X theme
